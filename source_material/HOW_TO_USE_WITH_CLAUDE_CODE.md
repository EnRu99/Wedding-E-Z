# How to use this pack with Claude Code

1. Unzip the folder.
2. Open Claude Code in a clean project directory.
3. Paste the contents of `CLAUDE_CODE_MASTER_PROMPT.md` into Claude Code.
4. Attach / point Claude Code to this whole folder.
5. Tell Claude Code to use this pack as the source of truth.
6. Let it build the invitation.
7. Ask it to run locally and iterate until it matches the premium direction.

## Useful follow-up instruction
After the first build, send:

"Now do a dedicated premium-polish pass. Compare the current implementation against the reference images, especially envelope feel, scratch interaction elegance, whitespace, typography, and the overall luxury mood. Simplify where necessary, refine spacing and visual hierarchy, and improve the invitation until it no longer feels like a generic template."
